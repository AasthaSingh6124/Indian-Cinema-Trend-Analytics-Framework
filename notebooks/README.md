# Project Notebooks

This folder contains the Jupyter notebooks used throughout the Indian Cinema Trend Analytics project.

The notebooks cover data collection, preprocessing, validation, feature engineering, exploratory analysis, topic modelling, sentiment analysis, and final research results.
