# Final Research Figures

This folder contains the 12 final visualizations generated by Notebook 11.

The figures cover:

- Nominal and inflation-adjusted India Gross comparisons
- Gross trends by rank and year
- Cinematic theme distributions and evolution
- Film-level dominant themes
- YouTube audience sentiment distributions
- Period-wise sentiment comparisons
- Year-adjusted theme–gross correlations
- Year-adjusted sentiment–gross correlations

These visualizations represent exploratory research results. Correlation does not imply causation.
