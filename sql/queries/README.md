# SQL Research Queries

This folder contains the SQL queries used for ICMB-130 analytical work in the Indian Cinema Trend Analytics project.

## Query files

- `01_ICMB_130_COMMERCIAL_PERFORMANCE.sql` — commercial performance analysis.
- `02_ICMB_130_DIALOGUE_THEME_ANALYSIS.sql` — dialogue-derived cinematic theme analysis.
- `03_ICMB_130_AUDIENCE_SENTIMENT_ANALYSIS.sql` — audience sentiment analysis.
- `04_ICMB_130_INTEGRATED_RESEARCH_ANALYSIS.sql` — integrated research analysis across project dimensions.

The queries are included as analytical documentation of the project workflow. They may require the project database schema and data tables to execute.
