# Processed Datasets

This folder contains the finalized datasets used in the Indian Cinema Trend Analytics project.

## Datasets

- ICMB_130_MASTER_DATA.csv — Master dataset containing 130 selected films and core metadata.
- ICMB_130_FINAL_INTEGRATED_FILM_ANALYTICS.csv — Integrated dataset containing film-level multimodal analytical features.
- ICMB_130_FINAL_INTEGRATED_INFLATION_ADJUSTED_2025.csv — Final integrated dataset with India Gross adjusted to 2025 CPI prices.
- INDIA_CPI_2000_2025_World_Bank.csv — CPI reference data used for inflation adjustment.

The dataset covers selected Indian films from 2000–2025.

Note: The dataset represents the selected benchmark films and should not be interpreted as a complete representation of the Indian film industry.
